# huseyinefeakpinar.com

A minimal personal academic/creative portfolio for Hüseyin Efe Akpınar.

## Structure
- `index.html` — home
- `about.html` — about and interests
- `writing.html` — writing archive
- `research.html` — research and published research
- `mun.html` — MUN leadership
- `poetry.html` — published poetry
- `cv.html` — web CV
- `css/style.css` — design system
- `js/main.js` — year footer helper
- `robots.txt`, `sitemap.xml` — search-engine basics

## Deployment
This is a plain static site. It can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or a conventional web host without a build step.

For a custom domain, point `huseyinefeakpinar.com` at the host you choose and follow that host's HTTPS instructions.

## Before going public
1. Replace any placeholder/future wording with concrete outputs as they become available.
2. Add a profile photo only if desired.
3. Add a PDF CV later if useful (the site currently uses a live HTML CV so no stale PDF is accidentally presented).
4. Review every external link once after deployment.
